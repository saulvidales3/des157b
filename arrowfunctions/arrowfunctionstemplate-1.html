Arrow Functions

This function greets a user by name. I found this example in DES 157A which reminded me of the classic line practically everyone learns to code which is "Hello World". I decided to make a function that is similar but instead of just saying "Hello World" it can say "Hello" followed by any name or word the user inputs.

Named Function

             function greet(name) {
                return "Hello " + name;
            }

            console.log(greet("Saul"));

Function Expression

             const greet = function(name) {
                return "Hello " + name;
            }

            console.log(greet("Saul"));

Arrow Function

            const greet = (name) => {
                return "Hello " + name;
            }

            console.log(greet("Saul"));
